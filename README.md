# Shortest Path Finder using Dijkstra's Algorithm

This Java application implements **Dijkstra’s Algorithm** to find the shortest path from a source node to all other nodes in a weighted graph. It’s commonly used in navigation systems, network routing, and logistics.

## 🚀 Features
- Graph representation using adjacency matrix
- Calculates shortest distances from a source node
- Demonstrates greedy strategy for path optimization

## 📦 How to Run

### Compile
```bash
javac DijkstraShortestPath.java
